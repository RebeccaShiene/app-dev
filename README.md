# My Favorite Series: The Walking Dead

## About the Show

**The Walking Dead** is a post-apocalyptic horror drama about survivors in a world overrun by zombies, called *walkers*.

### Main Characters

1. Rick Grimes
2. Daryl Dixon
3. Michonne

### Why I Like It

- Intense and suspenseful storylines
- Strong character development
- Shows how people survive in the worst situations
